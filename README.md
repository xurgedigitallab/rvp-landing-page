# TextRP Red vs Blue Challenge Landing Page

This is a landing page for the TextRP Texty Challenge at the XRP Las Vegas event. The page serves as an entry point for participants to learn about the challenge and join either the Red Team or Blue Team.

## Features

- Responsive design with Red vs Blue theme
- Information about the TextRP Texty Challenge
- Direct links to join team chat rooms
- Mobile-friendly layout

## Project Structure

```
textrp-landing/
├── images/
│   ├── textrp-logo.svg
│   └── red-vs-blue.svg
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Deployment

This landing page is designed to be deployed at `rvb.textrp.io` to provide information about the TextRP Red vs Blue challenge and direct users to the appropriate team rooms.

## Development

To run this project locally:

1. Clone the repository
2. Open the `index.html` file in your web browser
